Hybrid recommender

Content-basedTF-IDF + cosine

Product name, description and tags turned into vectors, with several of the customer's past purchases as starting points

CollaborativeXGBoost scoring

A trained model scores every customer–product pair by how likely a purchase is

RerankDiversity filter

Leaves out picks that are too similar to each other (cosine above 0.6), so each customer gets 5 varied products

⚙️

Engineering

  • Async delivery: aiohttp + asyncio with a semaphore capping sends at 50 at a time
  • Resilient LLM calls: retries with exponential backoff and jitter on 429, 5xx errors and timeouts
  • Per-customer short links: hashed codes stored in PostgreSQL, so click-through rate can be measured per segment
  • Human in the loop: each segment's template is reviewed and can be regenerated before anything is sent
  • Fast app: Streamlit caches the database connection and ML models
  • Modular code: separate modules for recommendations, LLM, templates, SMS and the database
