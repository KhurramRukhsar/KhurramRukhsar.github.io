⚙️

Engineering

  • Async delivery: aiohttp + asyncio with a semaphore capping sends at 50 at a time
  • Resilient LLM calls: retries with exponential backoff and jitter on 429, 5xx errors and timeouts
  • Per-customer short links: hashed codes stored in PostgreSQL, so click-through rate can be measured per segment
  • Human in the loop: each segment's template is reviewed and can be regenerated before anything is sent
  • Fast app: Streamlit caches the database connection and ML models
  • Modular code: separate modules for recommendations, LLM, templates, SMS and the database

04 — project deep dive

Which farmer needs help first?

I built a decision engine prototype at Bakhabar Kissan. It gives every crop-disease case reported by a farmer an urgency score from 0 to 10. The score combines agronomy knowledge, the crop's growth stage, how fresh the case is, and whether local weather is abnormal. An LLM then writes a short SMS advisory. The calculator here runs the same formula on the same knowledge base, so try it.

Weather is scored against sample 30-day norms for one location (95th-percentile max temperature 30 °C, 75th-percentile rain 5 mm). The real system works these norms out for every weather site from its own history. The SMS preview follows the same rules the system's LLM prompt enforces.

Agronomy knowledge base

0crop × disease × stage rules, each with a reason
0diseases rated by severity tier
0growth stages scored for sensitivity
0crops: wheat, cotton, rice, potato, sugarcane, mango
🌦️

Weather anomaly detection

  • Relative thresholds: 5th, 25th, 50th, 75th and 95th percentiles per site, calculated in SQL over the last 30 days
  • Local climate aware: 30 °C in a cool region raises urgency more than it would in a hot one
  • Composite signal: heat and cold extremes, rainfall spikes, snow, cloud cover, daily temperature swing and distance from the median
🤖

Guard-railed LLM advisory

  • Hard rules: under 150 characters, always includes the product name and full link, fixed signature
  • Risk-aware tone: CRITICAL cases start with "URGENT!"
  • No leaks: scores, case IDs and internal fields are never shown to farmers
  • Observable: an 11-step Streamlit pipeline with live logs and timing for each step
